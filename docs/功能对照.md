# iLovePDF 功能研究与 AIPDF 对照

研究日期：2026-09-05。研究范围是 iLovePDF 简体中文首页列出的 33 类工具，以及工作流程。按用户要求排除 AI 摘要与翻译后，应用保留 32 个工具入口，不下载或连接本地模型。复现工具用途与本地操作流程，采用独立的界面、名称和代码，不使用其商标、素材或云端接口。

## 已实现的本地能力

| 官网工具 | AIPDF 实现 | 范围与限制 |
| --- | --- | --- |
| 合并 PDF | 文件顺序调整、批量合并 | 交互表单同名字段独立保留；原有证书签名不保证继续有效 |
| 拆分 PDF | 逐页拆分、自定义范围分组 | 例如 `1-3;4-6` |
| 删除页面 | 按范围删除 | 不允许删除全部页面 |
| 提取页面 | 按范围提取 | 支持倒序范围 |
| 排列页面 | 缩略图调序、页码顺序、重复页面 | 多文件合并通过合并工具完成 |
| 扫描为 PDF | 图片导入、Vision 纸张识别和透视校正、增强/灰度 | 没有网站的手机二维码传输；可先用 iPhone 扫描并保存到 Mac |
| 压缩 PDF | 无损结构整理、图片重采样和 JPEG 压缩 | 保留文本；已优化文件不保证进一步缩小；透明图片跳过重采样 |
| 修复 PDF | MuPDF 自动恢复并重写文档结构 | 无法恢复已经丢失的原始数据 |
| OCR PDF | Apple Vision 中英文 OCR，写入不可见文字层 | 保留原页视觉；默认跳过已有文字页；需人工检查识别准确度 |
| JPG 转 PDF | JPG/PNG/TIFF/HEIC/BMP，A4/Letter/原尺寸、方向、边距 | HEIC 使用系统解码；每个输入文件导入一张图片 |
| PDF 转 JPG | JPEG/PNG 逐页导出、嵌入图片提取 | 嵌入提取保留原编码，不强制转 JPEG |
| Word 转 PDF | LibreOffice 本地转换 | 支持 doc/docx/odt/rtf；字体和复杂布局取决于安装环境 |
| PPT 转 PDF | LibreOffice 本地转换 | 支持 ppt/pptx/odp；不保留动画和视频 |
| Excel 转 PDF | LibreOffice 本地转换 | 支持 xls/xlsx/ods/csv；遵循打印分页设置 |
| PDF 转 Word | 可编辑文本/表格/图片；或逐页图像 | 不保证复杂排版还原；扫描件应先 OCR |
| PDF 转 PowerPoint | 原貌图片幻灯片；或文本框/图片重建 | 图片模式内容不可编辑；可编辑模式不完整重建矢量图形 |
| PDF 转 Excel | 按页识别表格、独立工作表 | 没有表格时导出文本；不恢复原始公式 |
| HTML 转 PDF | 本地静态 HTML、基础 CSS 与同目录图片；网址通过本机 WebKit 渲染 | 网址模式会联网获取网页资源；长页按 A4 分割，可能切开跨页元素 |
| PDF 转 PDF/A | LibreOffice 导出 1b/2b/3b | 检查 PDF/A 元数据；尚未集成 veraPDF 全标准校验，不能宣称已通过标准合规认证 |
| 旋转 PDF | 90°/180°/270°、指定页面 | 保留其他页面 |
| 添加页码 | 起始编号、格式、位置、字号、范围 | `{n}` 当前编号，`{total}` 所选页数 |
| 添加水印 | 中文文字/图片、位置、透明度、字号 | 不提供平铺或任意角度旋转 |
| 裁剪 PDF | 预览框选、数值范围、单页/多页 | 修改可视裁剪框；裁剪不是永久删除内容 |
| 编辑 PDF | 添加中文文字、图片、矩形、高亮、手绘 | 追加内容，不原位重排已有段落；每次输出可继续编辑 |
| PDF 表单 | 读取/填写、创建文本/复选/单选/列表 | 保留交互字段；没有 AI 自动识别普通纸质表单字段；单选组选项使用内部状态值填写 |
| PDF 解锁 | 已知密码认证后移除保护 | 不破解未知密码 |
| PDF 加密 | AES-256、打印/复制权限选项 | 权限由阅读器执行；打开密码由加密保护 |
| PDF 签名 | 本机手写、姓名、图片签名 | 可视签名；没有证书签名、邀请签署、身份认证、签署审计或时间戳 |
| PDF 标记密文 | 关键词/框选永久遮盖并重写输出 | 删除选区文字、图像像素、矢量内容；清理元数据、附件、表单、批注；仍需检查是否有其他页/其他位置的同类信息 |
| 比较 PDF | 并排视觉差异 PDF、文字差异 HTML | 按页序对照；不自动识别插入页和移动段落 |
| AI 摘要 | 按用户要求移除 | 不提供入口、模型配置或模型调用 |
| PDF 翻译 | 按用户要求移除 | 不提供入口、模型配置或模型调用 |
| PDF 转 Markdown | 标题、文字、表格、图片、链接提取 | 基于字号判断标题；复杂多栏和阅读顺序可能需整理 |
| 工作流程 | 按顺序串联 16 类 PDF 操作、保存/载入预设 | 最多 20 步；保留中间结果；预设不保存密码 |

## 应用能力

- 原生 SwiftUI / AppKit Mac 窗口，不需要浏览器或本地 Web 服务。
- 分类与搜索、文件拖入、系统文件选择、PDFKit 预览与框选。
- 多文件批处理、子进程取消、逐步状态、输出位置选择、Finder 定位。
- 源文件只读，每次输出到新的私有任务目录；最近 100 次处理记录保存在本机。
- 已填写密码只经子进程 stdin 传递，不写入参数、日志或流程预设。

## 与完整网站仍不等价的部分

这是本地桌面工具的初版实现，**不应称为 iLovePDF 的全部能力 1:1 完整替代**。主要差距是云端签署协作、手机扫码传输、账户/存储集成、专业级复杂版式还原、自动检测表单字段与认证过的 PDF/A 验证。AI 摘要和翻译已按用户要求排除，不属于后续待补功能。

## 分发依赖

当前为这台 Mac 的本地构建。Swift 可执行程序及 Python 处理代码放入 `.app`，Python 环境留在项目的 `.venv`，LibreOffice 从本机发现。没有内嵌 Python 或 LibreOffice；复制单个 `.app` 到其他电脑不是完整安装。

PyMuPDF/MuPDF 采用 AGPL 或商业许可；LibreOffice 等组件有各自许可证。在分发或商业化前，需要明确整个应用的开源/商业许可方案并整理第三方 notices。本仓库没有把第三方库的许可改写为自有许可。
