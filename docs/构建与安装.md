# 下载源码后，双击安装 AIPDF

这是**源码构建安装**：脚本负责安装 PDF 依赖、编译应用、放入“应用程序”并打开；不是免环境的预编译 DMG。首次需要 Python 和 Apple 编译工具。没有模型下载。

## 普通用户怎么做

1. 在 GitHub 仓库点击 **Code → Download ZIP**，下载并完整解压。不要只下载单个脚本。
2. 双击源码最外层的 **`Install.command`**。会打开终端并显示步骤。
3. 如果提示缺少基础组件，按下节完成安装，然后再次双击。
4. 等待出现“安装完成”。脚本默认安装到 `/Applications/AIPDF.app` 并启动；以后在 Finder 的“应用程序”或 Spotlight 搜索 **AIPDF** 即可。

安装成功后可以删除下载、解压的源码文件夹。应用所用的 Python 包已经独立安装在当前用户的数据目录，不依赖下载目录中的 `.venv`。

**仍需保留基础 Python。** 脚本没有把解释器或 LibreOffice 打进 `.app`；卸载或升级这些基础组件后可能需要重新运行安装脚本。该安装针对当前 Mac、当前用户，不能只把 `.app` 复制到另一台电脑或另一个用户就保证运行。

## 首次安装需要什么

| 组件 | 要求与安装方法 |
| --- | --- |
| macOS | 14 或更新版本；当前在 Apple Silicon / macOS 15.7.4 验证。Intel Mac 尚未实机验证。 |
| Apple Command Line Tools | 用于编译原生界面。缺失时脚本会打开系统安装提示；安装完成后重新双击脚本。也可在终端运行 `xcode-select --install`。 |
| Python | 支持 3.12—3.14，推荐 3.14。从 [Python 官网](https://www.python.org/downloads/macos/)安装；已有 Homebrew 的用户可运行 `brew install python@3.14`。脚本不会自行安装 Homebrew 或改系统 Python。 |
| 网络与磁盘 | 首次从 PyPI 安装锁定的依赖，需联网及足够空间。编译缓存、包下载缓存与旧版备份会额外占用磁盘。 |
| LibreOffice（可选） | Word/PPT/Excel 与 PDF/A 转换需要。在 [官网下载](https://www.libreoffice.org/download/download-libreoffice/)并放入“应用程序”；没有它也能使用其他工具。 |

此前约 650 MB 的数字是本机现有运行组件的合计，不包括首次安装 Apple 编译工具所需的下载和磁盘空间，也不是压缩后的安装包大小。

## 脚本会做什么

1. 检查系统、Python、Swift 和源码完整性。
2. 在 `~/Library/Application Support/AIPDF/Runtimes/` 新建隔离环境，按 `requirements.lock.txt` 安装依赖。环境版本与 Python、架构和锁文件关联，避免升级时破坏旧运行环境。
3. 编译三个原生程序；从本机实际安装的依赖收集许可，不修改仓库的审核快照。
4. 打包并验证签名。安装版 `Info.plist` 只记录运行环境 ID，不记录下载的源码绝对路径。
5. 校验处理引擎，然后安装应用。已有同名应用时先核对身份，保留旧版备份再替换；复制、校验或替换失败时保留/恢复旧版。
6. 保存安装记录并启动新版。脚本不会强制结束已经打开的旧版；建议安装前正常退出 AIPDF。

没有 `/Applications` 写权限时，会安装到 `~/Applications/AIPDF.app`，不索取管理员密码。多人共用一台 Mac 时，建议分别安装到各自的 `~/Applications`，避免共享应用被另一用户的环境配置替换。

不会下载 AI 模型，不会上传 PDF，不会把密码写入安装记录，也不会关闭 Gatekeeper。

## 文件放在哪里

| 内容 | 位置 |
| --- | --- |
| 应用 | `/Applications/AIPDF.app`；无权限时为 `~/Applications/AIPDF.app` |
| 用户运行环境 | `~/Library/Application Support/AIPDF/Runtimes/` |
| 安装记录 | `~/Library/Application Support/AIPDF/last-install.json` |
| 包下载缓存 | `~/Library/Application Support/AIPDF/Cache/pip/` |
| 构建暂存 | 用户数据目录中 `install-build-*` |
| 旧应用备份 | 应用程序目录中隐藏的 `.AIPDF-backup-日期-编号.app`；完整位置会打印并写入安装记录 |
| Swift 编译缓存 | 下载源码目录中的 `.build/`；删除源码后不影响已安装应用 |
| 文档输出 | 用户在应用中选择的文件夹，不随卸载自动删除 |

安装记录包含本机路径，**不要直接贴到公开 Issue**。确认新版正常后，可在 Finder 显示隐藏文件（`⌘⇧.`），移除不再需要的旧应用备份和构建暂存；运行环境目录不要随意删除。

## 更新、修复和卸载

- **更新**：下载新版源码，退出旧应用，再次双击 `Install.command`。相同且健康的运行环境会复用。
- **安装中断**：修复网络或磁盘问题后重试。脚本不会覆盖不属于 AIPDF 的同名应用，也不会主动清空用户数据。
- **Python 升级后打不开**：确保有支持的 Python 版本，重新运行安装脚本。虚拟环境本身不应直接移动或复制。
- **回退**：退出新版，在 Finder 中把备份应用移回原位置；保留它对应的运行环境。备份若是旧开发构建，仍需其原项目目录。
- **卸载**：退出 AIPDF，将应用拖入废纸篓。需要彻底清理时，可自行删除当前用户的 AIPDF 数据目录及旧备份；这会移除处理记录、流程预设和运行环境，但不会删除另存的文档。Python/LibreOffice 可能被其他软件共用，不要顺带卸载。

## 常见问题

**双击后被系统阻止**：只对确认可信的源码按 macOS 提示，在“系统设置 → 隐私与安全”允许本次打开。也可以打开终端，在解压目录运行 `zsh Install.command`。不要关闭全局安全检查。此项目还没有 Apple 公证的预编译安装包。

**只有下载 ZIP 中的一个文件**：需要整个仓库，包括 `Sources`、`backend`、`scripts` 和许可文件。

**找不到 Python**：脚本会寻找 PATH、Homebrew 常用路径和 python.org 标准安装位置中的支持版本。只支持的解释器可通过下面的维护者命令显式指定。

**证书或包下载失败**：使用正常可信的网络，并检查 Python 安装是否完整；python.org 安装后可按其说明运行附带的证书安装程序。不要通过关闭 TLS 校验解决。

**没有适合当前版本/架构的 wheel**：安装脚本只接受二进制 wheel。先换用支持的 Python 版本；若仍失败，请提供系统、架构、Python 版本和不含私人路径的错误摘要。

## 维护者命令

```sh
# 只检查，不安装或启动
zsh Install.command --check

# 安装但不自动启动
zsh Install.command --no-launch

# 安装到当前用户的应用程序目录
zsh Install.command --applications-dir "$HOME/Applications"

# 显式指定已经安装的 Python 解释器
python3.14 scripts/install.py --no-launch

# 原来的开发构建仍可使用，依赖项目 .venv，输出 dist/AIPDF.app
zsh scripts/build.sh

# 验证安装逻辑（只操作临时合成应用）
.venv/bin/python tests/test_installer.py
```

分发许可证、对应源码、隐私和安全边界仍适用，见 [分发说明](分发说明.md)。源码安装脚本并不等同于通过签名、公证和干净机器验证的通用安装包。

参考：[Python 虚拟环境](https://docs.python.org/3/library/venv.html)、[Apple Command Line Tools](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools)、[macOS 打开未知开发者应用](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)。
